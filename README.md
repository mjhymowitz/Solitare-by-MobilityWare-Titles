# Solitare-by-MobilityWare-Titles

This repository documents the titles used in the iOS app [Solitaire by MobilityWare](https://apps.apple.com/us/app/solitaire-by-mobilityware/id284791396).

The only purpose of this repo is to list each title and the level where that title is earned from levels 1-1000.

After level 1000, the title cycle repeats and appends a number after the title:

- Levels 1-1000: `{title}`
- Levels 1001-2000: `{title} 2`
- Levels 2001-3000: `{title} 3`
- And so on for each additional 1000 levels.
